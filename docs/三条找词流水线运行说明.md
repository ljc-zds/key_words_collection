# 三条找词流水线运行说明

本说明定义当前可独立运行的三条找词流水线。它不会替代或修改
`关键词挖掘完整流程.md`；旧文档保留为历史完整流程与策略参考。

## 代码位置

```text
product_hunt_daily.py                         # Product Hunt + AITDK 入口
keyword_loop/workflows/
  product_hunt/
    cli.py                                    # Product Hunt + AITDK 入口
    pipeline.py                               # Product Hunt 编排
    aitdk/                                    # MCP 与 AITDK 采集能力
  discovery/
    cli.py                                    # Similarweb + Semrush 入口
    pipeline.py                               # 发现编排
  validation_publish/
    cli.py                                    # 深度验证与发布入口
    pipeline.py                               # 验证与发布编排
keyword_loop/core/                             # 两个工作流共用能力
```

## 运行顺序

```text
1. Product Hunt + AITDK：发现已验证的新站方向
2. Similarweb + Semrush：建立关键词候选池
3. 深度验证与发布：AI、SERP、哥飞 KD 后写入关键词飞书表
```

三条任务可以在不同时间运行。第二条只写 SQLite，第三条只读取 SQLite
候选并发布完整记录，因此不会重复采集 Similarweb 数据。

## 1. Product Hunt + AITDK

入口：`product_hunt_daily.py`

输入：Product Hunt 前一天产品、已登录 AITDK 扩展的 Chrome CDP 会话。

输出：Product Hunt 飞书表和 `runtime/product_hunt_daily.json`。它不写入关键词
候选飞书表，也不调用 Similarweb、Semrush、AI、Serper 或哥飞 KD。

运行前启动含 AITDK 扩展的独立 Chrome：

```zsh
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --remote-debugging-port=9222 \
  --remote-allow-origins='*' \
  --user-data-dir="/Users/am/Documents/代码/key_words_collection/runtime/keyword-loop-profile"
```

运行命令：

```bash
PYTHONPATH=. .venv/bin/python product_hunt_daily.py
```

若 Chrome、CDP 或 AITDK 登录状态异常，记录会标为 `error`。恢复后重试：

```bash
PYTHONPATH=. .venv/bin/python product_hunt_daily.py --retry-errors
```

完整 AITDK MCP 前置条件见 `AITDK_CDP_MCP.md`。

## 2. Similarweb + Semrush 关键词发现

入口：`keyword_loop/workflows/discovery/cli.py`

输入：Stripe 榜单、Toolify 榜单、飞书词根库，以及已登录 Similarweb/Semrush 的
Chrome CDP 会话。

输出：`output/keyword-loop.sqlite3` 中的关键词观察、Semrush 验证、来源归属与断点。
该脚本不调用 AI、Serper、哥飞 KD，也不写入最终关键词飞书表。

```bash
PYTHONPATH=. .venv/bin/python -m keyword_loop.workflows.discovery.cli \
  --cdp-url http://127.0.0.1:9222 \
  --roots-feishu-url '词根飞书链接' \
  --sources stripe,toolify,root \
  --source-limit 20 \
  --semrush-limit 60
```

单个来源词失败时会记录到 SQLite，来源偏移不会越过失败项；重新执行相同命令即可续跑。
旧命令 `run_discovery_semrush_only.py` 仍可使用，行为等同于此脚本。

## 3. 深度验证与关键词发布

入口：`keyword_loop/workflows/validation_publish/cli.py`

输入：第二条脚本已存入 SQLite 且通过 Similarweb/Semrush 门槛的关键词。

阶段：Semrush 精确词复核、AI 初筛、Serper SERP、哥飞 KD、AI 最终判断、飞书发布。

输出：完整通过的关键词写入指定的关键词飞书表；失败或未完成的关键词保留在 SQLite，
不会发布半成品。

```bash
PYTHONPATH=. .venv/bin/python -m keyword_loop.workflows.validation_publish.cli \
  --cdp-url http://127.0.0.1:9222 \
  --results-feishu-url '关键词结果飞书链接' \
  --limit 60
```

该脚本会消耗 Semrush、AI、Serper、哥飞 KD 和飞书 API 配额。由于所有阶段结果都
写入 SQLite，重复运行会跳过已完成的 Serper 与哥飞 KD 数据，并继续未完成的队列。
旧命令 `run_daily_gates.py` 仍可使用，行为等同于此脚本。

## 每日建议

1. 确保 `9222` Chrome 中已登录 AITDK、Similarweb 和 Semrush。
2. 运行 Product Hunt 脚本，发现已获得新站流量验证的方向。
3. 运行关键词发现脚本，补充 Stripe、Toolify 与词根候选池。
4. 运行深度验证发布脚本，完成 AI/Serper/哥飞 KD 后增量写入关键词飞书表。
5. 次日先重跑失败或未完成队列，再开始新一轮采集。
