# 关键词 MVP 建站优先级

更新日期：2026-09-02  
数据来源：[飞书关键词表](https://my.feishu.cn/wiki/VHnXwGzGQiGeUkkgj4tc4kpLnbh?sheet=e2e503)；Semrush US、Similarweb、哥飞 KD、Serper 与 AI 二筛数据。

## 结论

第一阶段只启动三个 MVP：

1. `final grade calculator`：首个正式站点，验证学生计算器细分。
2. `minecraft circle generator`：首个纯前端静态工具，验证快速发布与自然流量获取。
3. `ebay fee calculator`：首个高商业价值工具，验证维护型数据工具的变现能力。

选择标准不是搜索量最大，而是同时满足：用户要立即得到计算结果、一个小团队能在数天内发布可用版本、无需依赖难以获得的实时数据、竞争和外链成本在可承受范围内。

## 评估口径

- Semrush 搜索量和 KD：Google US 的最终验证口径。
- 哥飞 KD 与链接预算：进入前十的竞争成本参考，不是保证排名。
- AI 工具页适配度：只表示查询适合工具页，不能替代竞争判断。
- 强站数量：Serper 前十中 Wikipedia、Reddit、YouTube、政府或教育站等强站信号；数值低不代表没有成熟的垂直产品。
- MVP 优先级额外考虑：数据维护成本、合规风险、是否可以复用成工具集群。

## 立即启动

### 1. Final Grade Calculator

这是最适合先做的主项目。用户任务单一且频繁：输入目前成绩、课程权重和期末目标，直接得到期末最低所需分数。它不需要第三方 API，结果可验证，且能够从单页自然扩展成学生计算器站。

| 指标 | 数据 |
| --- | --- |
| Semrush US 搜索量 / KD | 165,000 / 49 |
| Similarweb 搜索量 / KD | 520,100 / 26 |
| 哥飞 KD | 45.3 |
| 哥飞链接预算 | 50-110 个引用域 |
| AI 二筛 | 88，工具页与关键词域名适配度均为 high |
| 强站数量 | 0 |

MVP 必须包含：当前总评、各作业/考试权重、期末目标分数、百分制/字母成绩切换、可分享结果链接，以及公式与 FAQ。首版不做账户、社区或 AI 功能。

后续集群：`grade calculator`、`gpa calculator`、`weighted grade calculator`、`exam score calculator`。其中 `gpa calculator` 的哥飞 KD 为 66.3、链接预算 120-260，应在站点已有权重后再进入。

#### 学生成绩计算器站实施方案

站点定位：面向美国高中和大学学生的无登录成绩计算工具。首期只解决“我期末至少要考多少分”和“加权后的当前总评是多少”，不要一开始做课程管理、账户体系、AI 辅导或校园社区。

首批页面按以下顺序发布：

1. `/final-grade-calculator/`：主页面。输入当前总评、期末权重和目标总评，输出期末最低所需成绩。
2. `/weighted-grade-calculator/`：输入作业、测验、考试和各自权重，输出当前加权成绩。
3. `/exam-score-calculator/`：输入题数、正确题数或已知百分比，输出分数、错误题数和目标正确题数。
4. `/grade-percentage-calculator/`：输入得分与满分，输出百分比、字母成绩和反向目标分数。

页面之间必须使用内部链接串成一个工具集，而不是孤立的四个页面。每个页面只覆盖一个主搜索意图，标题、H1、FAQ 和示例围绕该页主词展开。

**MVP 功能边界**

| 模块 | 首版要求 | 不进入首版 |
| --- | --- | --- |
| 计算 | 浏览器本地实时计算；输入变化后立即刷新结果 | 服务端账户、保存课程历史 |
| 输入 | 百分制、字母等级切换；可添加/删除成绩项；权重校验 | 学校 LMS 导入、成绩单 OCR |
| 结果 | 最终成绩、目标所需分数、计算步骤、异常提示 | AI 学习建议、个性化课程规划 |
| 内容 | 公式说明、一个真实示例、3-5 个 PAA FAQ | 大篇幅泛教育文章 |
| 分享 | 将输入编码到 URL，支持复制结果链接 | 用户登录、云端保存 |

**核心公式**

设当前总评为 `C`，期末权重为 `W`，目标最终总评为 `T`。所有数值用 0-100 的百分制表示，则所需期末分数为：

```text
required_final = (T - C * (1 - W)) / W
```

必须处理三类边界：结果大于 100 时明确提示“即使期末满分也无法达到目标”；结果小于等于 0 时提示“已达到目标”；权重总和不等于 100% 时阻止计算并指出差额。字母成绩换算必须让用户选择或查看使用的分档，不能假设所有学校采用同一标准。

**技术方案**

- 优先使用静态站点和纯前端 TypeScript；所有计算在本地完成，不收集成绩数据。
- 计算逻辑独立为可测试函数，四个页面共用输入校验、百分比格式化、URL 状态编码和结果卡片组件。
- 不需要数据库、认证、第三方 API 或付费模型调用。
- 首版提供事件记录：页面访问、首次完成计算、复制链接、切换工具页。只记录匿名事件，不记录原始成绩输入。
- 发布前为每个公式写单元测试，覆盖正常值、权重边界、负数、超过 100 和小数精度。

**两周发布节奏**

| 时间 | 交付 |
| --- | --- |
| 第 1-2 天 | 计算内核、输入校验、`final grade calculator` 页面和移动端测试 |
| 第 3-4 天 | FAQ、公式解释、结构化数据、内部链接和事件记录 |
| 第 5-7 天 | 发布 `weighted grade calculator` 与 `exam score calculator`，复用组件和测试 |
| 第 2 周 | 发布 `grade percentage calculator`；根据真实搜索词补充 FAQ 和页面文案 |

**上线验收**

- `final grade calculator` 可在移动端和桌面端无登录完成计算。
- 任意结果均能展示计算步骤，且所有异常输入有明确提示。
- 首批四页拥有独立 title、H1、canonical、FAQ 内容和相互内部链接。
- Lighthouse 性能、可访问性和 SEO 不低于 90；表单与结果区不发生布局跳动。
- 分析面板可看到完成计算和复制链接两个关键事件。

### 2. Minecraft Circle Generator

这是开发成本最低的流量实验。用纯前端就能提供即时可视化结果，不需要账户、上传文件或外部数据。用户在 SERP 中明确寻找生成器，而不是教程文章。

| 指标 | 数据 |
| --- | --- |
| Semrush US 搜索量 / KD | 33,100 / 28 |
| Similarweb 搜索量 / KD | 86,700 / 12 |
| 哥飞 KD | 50.8 |
| 哥飞链接预算 | 60-130 个引用域 |
| AI 二筛 | 88，工具页与关键词域名适配度均为 high |
| 强站数量 | 1 |

MVP 必须包含：圆形、椭圆、圆环；半径/直径/厚度参数；方块数量；网格预览；复制清单或 PNG 导出；移动端可用。建议站点品牌使用通用的 `Pixel Circle Generator`，在页面中说明适用于 Minecraft 建造，避免将 Minecraft 用作产品品牌或暗示官方关联。

后续集群：pixel sphere、dome、arch、circle outline、block count 等同一套网格算法页面。

### 3. eBay Fee Calculator

这是商业价值最强的优先项。CPC 高，搜索者接近卖货决策，工具可以通过卖家模板、联盟推荐或专业版功能变现。但它不是完全静态工具，必须对费率变化负责。

| Semrush US 搜索量 / KD | 22,200 / 45 |
| Similarweb 搜索量 / KD | 90,700 / 32 |
| Semrush CPC | $6.84 |
| 哥飞 KD | 45.4 |
| 哥飞链接预算 | 50-110 个引用域 |
| AI 二筛 | 86，工具页与关键词域名适配度均为 high |
| 强站数量 | 0 |

MVP 必须包含：售价、运费、商品成本、类目费率、店铺订阅、推广费、利润和保本售价。每次费率更新都要显示生效日期、来源链接和计算假设。首版只支持 US，避免在不完整的国际费率下给出错误结果。

后续集群：`ebay calculator`、margin calculator、shipping profit calculator、marketplace fee comparison。

## 值得排队，但不应抢在前三之前

### Coast FIRE Calculator

Semrush 为 18,100 / KD30，哥飞 KD29.2，链接预算仅 25-50，竞争信号很好。问题是金融内容属于 YMYL：必须公开公式、假设和免责声明，且不能给出个性化投资建议。适合作为第四个项目。

### DevEx Calculator

Similarweb 为 41,400 / KD7，哥飞 KD31，链接预算 25-55；开发极轻。Semrush 未返回精确关键词，需在上线前再次确认 US 搜索量。首版可做 Robux 到 USD 换算、开发者兑换门槛和费率说明；应标明非 Roblox 官方工具并维护规则更新时间。

### CPM Calculator

Semrush 为 27,100 / KD27，CPC $5.91，适合营销从业者。输入预算、曝光、CPM、CTR、CPC 中任意两到三项即可互算。它适合作为营销计算器站的第一页，但单独做站的品牌和长尾扩展空间小于前三项。

### Fantasy Football Trade Analyzer 集群

数据很漂亮：Semrush 90,500 / KD38，哥飞 KD20.5、链接预算 15-35。但真正竞争力来自实时球员价值、联盟规则、新秀签与赛季更新，而不是计算器壳。没有稳定数据来源之前，不应仓促发布；有可靠数据源后可作为高潜力第二阶段项目。

### Satisfactory Planner

Similarweb 为 29,600 / KD6，哥飞 KD43。用户需求真实，但需要维护游戏配方、版本和产线模型。若已有可复用的游戏数据管线，它可以进入游戏工具项目队列；否则优先级低于纯计算器。

## 暂缓或排除

| 关键词/类别 | 原因 |
| --- | --- |
| `png to pdf`、`pdf to png` | 哥飞链接预算约 180-440，成熟转换站竞争和文件安全/基础设施成本很高。 |
| YouTube MP3/MP4 转换相关词 | 版权、平台规则与域名稳定性风险高。 |
| `gpa calculator` | 搜索量大，但哥飞 KD66.3、链接预算 120-260，适合在学生站建立权重后再做。 |
| RMD、Roth IRA、所得税、销售税计算器 | 金融 YMYL 与法规变动成本高，需要额外合规与来源维护。 |
| body fat、protein、macro calculator | 有需求，但健康解释、可信度要求和成熟竞争者更重。 |
| 宽泛文件转换器和通用计算器 | 虽有工具意图，但缺少差异化时会被成熟品牌和工具聚合站压制。 |

## 发布顺序与验收

### 第一个月

1. 发布 `final grade calculator`，同时准备 3 个学生计算器长尾页。
2. 发布 `minecraft/pixel circle generator`，用同一算法推出圆环和椭圆页面。
3. 发布 `ebay fee calculator`，建立费率配置文件和月度核验流程。

每个 MVP 的首版验收标准：

- 用户无需注册即可在 10 秒内完成一次计算或生成。
- 结果可解释，关键公式或数据假设在页面可见。
- 页面针对一个主词，不混合多个不相干工具。
- 有至少 3 个对应 PAA 或相关搜索的 FAQ/长尾内容区块。
- 有基础事件记录：访问、完成计算/生成、复制/下载、外链点击。

## 决策复核

上线前再次检查：当前 Google US SERP 前十、产品是否有可验证的正确性标准、是否需持续更新外部数据、是否存在商标/版权/YMYL 限制。若任一项不能满足，优先做下一个静态且低维护的候选，而不是为了搜索量强行启动。
